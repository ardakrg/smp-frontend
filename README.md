# SMP Web App — Frontend

A web application developed for [Saturday Morning Physics](https://www.iap.tu-darmstadt.de/smp/saturday_morning_physics/index.de.jsp) at TU Darmstadt — a public physics lecture series for high school students. Built as part of the Software Development Project course (2025) in a team of 5.

## Features

- Role-based UI for Organizers, Participants, and HiWis
- QR code-based attendance scanning
- Event registration and approval workflows
- JWT-based authentication

## Tech Stack

React · TypeScript · Vite

## Setup

1. `npm install`
2. `npm run dev`
3. Open http://localhost:5173

> The backend must be running for the app to work. See [smp-backend](https://github.com/ardakrg/smp-backend).
